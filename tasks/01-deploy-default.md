# Инструкция. Задание 1 — Деплой без конфигурации

**Цель:** увидеть, как приложение ведёт себя на значениях по умолчанию,
и понять, откуда они берутся.

**Понадобится:** задание 0 (образ `calc-app:v2`), шаблон
`templates/deployment-v2.yaml`.

---

## Ход работы

### Шаг 1. Заполните и примените deployment

В `templates/deployment-v2.yaml` заполните `<ВПИШИТЕ ...>`
(блок envFrom пока оставьте закомментированным):

```bash
kubectl apply -f templates/deployment-v2.yaml
kubectl rollout status deployment/calc-app -n demo
```

### Шаг 2. Посмотрите конфигурацию

```bash
kubectl port-forward deployment/calc-app 5000:5000 -n demo &
curl http://localhost:5000/config
```

### Шаг 3. Подумайте

В ответе `"app_name": "calc-app"`, `"calc_precision": 2` —
но в манифесте вы этого не писали. **Не подсматривая в следующий
абзац**, найдите, откуда взялись эти значения. Подсказка: они зашиты
в образ — где именно? (`docker run --rm calc-app:v2 env` не покажет —
они не в ENV образа. Посмотрите в код: `grep -n "getenv" app/app.py`.)

Остановите port-forward: `kill %1`.

✔ **Контрольная точка:** вы нашли умолчания в коде и можете объяснить,
почему «зашитые» значения — это проблема для prod.

## Что сдать в отчёте

Вывод /config и ответ: где заданы умолчания?
