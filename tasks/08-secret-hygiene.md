# Инструкция. Задание 8 — Гигиена секретов

**Цель:** закрепить правила обращения с секретами на практике.

---

## Ход работы

### Шаг 1. Опасная привычка

Выполните и подумайте, что плохого:

```bash
kubectl get secret db-credentials -n demo -o yaml > my-secret.yaml
git status    # представьте, что вы в репозитории
```

Письменно: почему файл `my-secret.yaml` нельзя коммитить, хотя
«там же base64, не пароль»?

### Шаг 2. Создание Secret из файла манифеста

Можно и декларативно — `templates/secret.yaml`. Посмотрите: значения
там в base64. Закодируйте сами:

```bash
echo -n "newpassword" | base64
```

Впишите результат в шаблон, примените, проверьте декодированием.

### Шаг 3. Уберите за собой

```bash
rm -f my-secret.yaml
```

## Что сдать в отчёте

Ответ из шага 1 и рабочий secret.yaml с вашим значением.
