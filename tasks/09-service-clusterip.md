# Инструкция. Задание 9 — Service ClusterIP: вход изнутри

**Цель:** поднять стабильную точку входа и доказать, что снаружи
она недоступна.

---

## Ход работы

### Шаг 1. Создайте сервис

Заполните `templates/service-clusterip.yaml` (тип, selector, порты
80 → 5000). Примените.

```bash
kubectl get svc calc-service -n demo
```

### Шаг 2. Снаружи — нельзя

```bash
curl --max-time 5 http://localhost/calc
```

Ничего не вышло — и это правильно. Объясните письменно почему.

### Шаг 3. Изнутри — можно

Запустите одноразовый под с curl **внутри кластера**:

```bash
kubectl run curl-test --rm -i --image=curlimages/curl -n demo \
  --restart=Never --quiet -- curl -s "http://calc-service/calc?op=mul&a=6&b=7"
```

Работает — по имени сервиса, без IP.

✔ **Контрольная точка:** можете объяснить, почему с хоста нельзя,
а из пода — можно.

## Что сдать в отчёте

Выводы шагов 2–3 и объяснение.
