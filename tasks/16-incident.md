# Инструкция. Задание 16 — Инцидент: «приложение не отвечает»

**Цель:** отладить сломанную цепочку доступа. Готовых команд почти нет —
есть симптом и ваш опыт блока.

---

## Вводные

Преподаватель (или вы сами, честно не подглядывая дальше) применяет
набор манифестов из `templates/broken/`. Симптом:

```bash
curl http://calc.local/health
# нет ответа / 404 / 503
```

## Задача

Найдите и почините **три** спрятанные поломки. Методика:

1. Сверху вниз по цепочке: имя резолвится? → ingress есть и с ADDRESS?
   → правило указывает на существующий сервис и порт? → у сервиса есть
   endpoints? → поды живы и готовы (READY)? → приложение внутри слушает
   тот порт?
2. Фиксируйте каждую находку командой-доказательством.
