# Инструкция. Задание 15 — Два приложения через один Ingress

**Цель:** челлендж без готовых команд: второе приложение рядом с первым.

---

## Задача

1. Запустите `nginx` в namespace demo (Deployment, 1 реплика,
   образ `nginx`, порт 80).
2. Создайте для него Service (какого типа? решите сами).
3. Допишите Ingress так, чтобы `web.local` вёл на nginx,
   а `calc.local` — по-прежнему на калькулятор.
4. Добавьте имя в /etc/hosts по аналогии.
5. Проверьте оба адреса curl'ом.

Подсказок по манифестам нет — берите за образец файлы из заданий 9 и 14.

## Подумайте

Можно ли одним Ingress-объектом обслужить оба хоста? А нужно ли?
