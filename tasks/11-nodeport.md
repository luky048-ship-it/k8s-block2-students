# Инструкция. Задание 11 — NodePort: выходим наружу

**Цель:** открыть приложение снаружи кластера через порт узла.

---

## Ход работы

### Шаг 1. Переключите тип

```bash
kubectl patch svc calc-service -n demo -p '{"spec":{"type":"NodePort"}}'
kubectl get svc calc-service -n demo
```

Появился порт вида `80:31919/TCP`.

### Шаг 2. Откройте приложение

```bash
minikube service calc-service -n demo --url
```

> **macOS + docker-драйвер:** эта команда поднимает туннель на
> 127.0.0.1 — окно терминала с ней держите открытым, а curl выполняйте
> из второго терминала.

```bash
curl "<URL-из-команды>/calc?op=mul&a=6&b=7"
```

### Шаг 3. Подумайте

Диапазон NodePort ограничен (30000–32767) и порт открыт на всех узлах.
Представьте 200 приложений в кластере — в чём проблема? Какой объект
решает её (следующее задание)?
