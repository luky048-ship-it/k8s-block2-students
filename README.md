# Kubernetes. Блок 2 — Конфигурация и доступ

Лабораторная по мотивам блока 2 курса: ConfigMap, Secret, типы Service,
Ingress. Приложение настраивается без пересборки образа и публикуется
по человеческому адресу.

**Предусловие:** пройден блок 1 (Pod, Deployment, Service, kubectl,
minikube работает).

## Как работать

1. Задания — в `tasks/`, по порядку: `00-setup` … `17-review`.
2. В каждом задании — шаги и контрольные точки. Пропуски
   `<ВПИШИТЕ ...>` в шаблонах из `templates/` заполняете сами.
3. Многие задания просят сначала подумать и ответить, потом чинить —
   не пропускайте эти места, они и есть суть.
4. `slides.html` — презентация с теорией и схемами (открыть в браузере).
5. По каждому заданию в конце написано, что сдать в отчёт.

## Демо-приложение

`app/` — калькулятор v2 (Flask): `GET /calc?op=mul&a=6&b=7`,
`GET /config` — текущая конфигурация (видно, что подхватилось из
ConfigMap/Secret), `GET /health`. Порт 5000.

## Если что-то не работает

- `minikube` не отвечает → `minikube start --driver=docker`.
- `ImagePullBackOff` / `ErrImageNeverPull` → образ не загружен в
  minikube: `docker build -t calc-app:v2 app/ && minikube image load calc-app:v2`.
- `minikube service` «висит» — на macOS это туннель, так и должно быть;
  curl — из второго терминала.
- Полный сброс: `kubectl delete namespace demo` (и создать заново).
